# downloads/

This directory holds the **free** PDF files served by `/api/resources/download/[id]`.
Premium PDFs live in `apps/web/private/downloads/` — outside `public/` so they
cannot be fetched by URL; they are served only through the signed-link route
`/api/resources/premium/download` after a verified Razorpay payment.

Each file corresponds to a `fileName` value in `src/lib/resources.json`.

All six PDFs are generated by `scripts/generate_resource_pdfs.py` (repo root),
which reads every IRCC figure from `src/lib/crs-rules.json` so the documents
can never drift from the calculator. Re-run the script to regenerate after a
rules update.

## Current files (free)

- `ee-document-checklist.pdf`
- `ielts-clb-crs-cheatsheet.pdf`
- `ita-to-pr-roadmap.pdf`

## Adding a new free resource

1. Add the entry to `resources.json` and regenerate or drop the PDF here with
   the exact `fileName`.
2. The download API serves it automatically — no code changes needed.

If a registered file is missing, the route returns HTTP 503 ("File not
available yet") rather than 404, to distinguish a pending upload from an
unknown resource id.
