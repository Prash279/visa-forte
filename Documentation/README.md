## Documentation Standards
- All documentation files use Markdown format
- File names use kebab-case (e.g., `tech-stack.md`)
- Each subdirectory contains an index.md file
- Documentation is version controlled with Git

## Using This Documentation
1. Start with Design/ for visual and UX specifications
2. Reference Technical/ for implementation details
3. Use Resources/ for content and asset guidelines
4. Follow Development/ for build and deployment guides
